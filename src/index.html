💬 对话设置 (LLM)

选择供应商自动填充地址与模型。「获取模型列表」会请求该接口的 GET /models 并填入下拉建议。
📷 屏幕视觉需要多模态模型：阿里百炼 qwen-vl-plus / OpenAI gpt-4o / 智谱 glm-4v / 小米 MiMo-VL 等。

🔊 语音合成设置 (TTS)

Fish Audio：语音填声音 ID（reference_id），「获取可用音色」会拉取你账号下的音色。小米内置音色：冰糖 / 茉莉 / 苏打 / 白桦 / Mia / Chloe / Milo / Dean。系统语音按所选语言自动挑选。

🎤 语音识别设置 (STT)

Whisper 兼容端点也可用 Groq（https://api.groq.com/openai/v1，模型 whisper-large-v3）。小米 ASR 自动用其专属接口，无需填 Base URL。

更换模型 / 语音

保存后立即生效；人设、开场白等更多设定请用「编辑角色卡」。
